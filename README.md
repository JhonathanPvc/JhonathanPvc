# 👨‍💻 Jhonathan Cordeiro

**`Engenheiro de Software`**
<p align="justify">
Sou engenheiro de software com mais de nove anos de experiência em desenvolvimento front-end e back-end, especializado em Java, TypeScript, Spring Boot e Dart, com sólida atuação em arquitetura de microserviços e criação de APIs escaláveis. Tenho experiência prática com frameworks modernos como Angular, Flutter, React e Vue.js, além de bancos de dados como PostgreSQL, MySQL e Oracle SQL. Ao longo da minha carreira, mantenho foco em qualidade de código por meio de testes unitários com JUnit, Mocha, Chai e Jest, aplicando metodologias ágeis como Scrum para entregar soluções eficientes e inovadoras em projetos complexos e colaborativos.
</p>
